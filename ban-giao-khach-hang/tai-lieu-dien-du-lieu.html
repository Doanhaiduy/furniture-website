Phần 1

Bộ file & nguyên tắc điền

Trước khi website “lên sóng”, đội kỹ thuật cần dữ liệu thật của cửa hàng. Bạn điền vào bộ file Excel có sẵn trong thư mục file-dien-du-lieu/, kèm gửi các file ảnh.

1.1 · Bộ 5 file cần điền

1.2 · Nguyên tắc điền chung

  • Cột có dấu * (nền xanh đậm) là bắt buộc.
  • Có dòng mẫu (chữ nghiêng, nền xanh nhạt) để tham khảo — xoá đi rồi nhập dữ liệu thật, hoặc nhập từ dòng trống bên dưới.
  • Click vào ô sẽ hiện gợi ý; một số ô có dropdown để chọn.
  • Không đổi tên cột, không xoá dòng tiêu đề.
  • Giá tiền: chỉ nhập số, không dấu chấm/phẩy, không chữ “đ”. Đúng: 45000000.
  • Ảnh: KHÔNG dán ảnh vào Excel — ghi tên file vào ô, rồi gửi kèm tất cả ảnh.

Phần 2

Thứ tự & cách gửi ảnh

2.1 · Điền theo đúng thứ tự 1 → 5

File sản phẩm tham chiếu tới danh mục/thương hiệu/showroom bằng TÊN. Vì lúc khởi tạo chưa có dữ liệu nào, ta liên kết bằng tên:

⚠️Quan trọngHoàn thành file 1 (Danh mục), 2 (Thương hiệu), 3 (Showroom) trước, rồi mới điền file 4 (Sản phẩm) và ghi đúng y hệt cái tên đã khai. Ví dụ: file 1 có danh mục “Sofa phòng khách” → cột Danh mục trong file sản phẩm ghi đúng “Sofa phòng khách”.

2.2 · Cách gửi ảnh

  1. Tạo một thư mục ảnh trên máy, ví dụ ANH-WEBSITE.
  2. Đặt tên file ảnh không dấu, không khoảng trắng (ví dụ sofa-y-01.jpg, logo.png, hero-1.jpg).
  3. Trong Excel, ô ảnh ghi đúng tên file đó.
  4. Nén cả thư mục thành file .zip và gửi kèm các file Excel.

Phần 3

Chi tiết từng file

① 1_Danh_muc_san_pham.xlsx

  • Điền danh mục cha trước (để trống cột “Danh mục cha”), rồi danh mục con (ghi tên cha vào cột “Danh mục cha”).
  • Chọn Nhóm hàng từ dropdown: Đồ gỗ nội thất / Thiết bị vệ sinh / Gạch ốp lát / Khác.
  • ⚠️ Sản phẩm chỉ gắn được vào danh mục con — hãy tạo đủ danh mục con.

② 2_Thuong_hieu.xlsx

  • Mỗi dòng một thương hiệu. Tên tiếng Anh & mô tả để trống nếu không có.
  • Có logo thì ghi tên file logo và gửi kèm.

③ 3_Showroom.xlsx

  • Bắt buộc: Tên showroom, Tỉnh/Thành, Địa chỉ, Hotline, URL bản đồ nhúng Google Maps.
  • Lấy URL bản đồ nhúng: Google Maps → tìm địa chỉ → Share → Embed a map → copy đoạn link trong src="…".

④ 4_San_pham.xlsx quan trọng

  • Điền sau khi xong file 1, 2, 3.
  • Bắt buộc: Tên sản phẩm, Danh mục, Mô tả ngắn, Ảnh chính.
  • Cột Danh mục / Thương hiệu / Showroom: ghi đúng tên như file 1/2/3.
  • Cột Nổi bật: chọn “Có” để ưu tiên hiển thị. Chưa có mô tả chi tiết thì để trống (bổ sung sau trong Admin, hoặc AI hỗ trợ soạn).

⑤ 5_Thong_tin_cua_hang.xlsx

  • File dạng biểu mẫu: điền nội dung vào cột màu vàng “Nội dung cần điền”.
  • Gồm 7 phần: Nhận diện thương hiệu, Liên hệ, Mạng xã hội, SEO, Slide Hero trang chủ, Câu chuyện thương hiệu, Huy hiệu tin cậy.
  • Ảnh (logo, favicon, hero, story) — ghi tên file và gửi kèm.
💡Về sau muốn thêm sản phẩm mới, bạn có thể tự làm trực tiếp trong Admin (Quyển 1), hoặc tiếp tục dùng chức năng Nhập Excel ngay trong Admin.

Phần 4

Checklist trước khi gửi

Kiểm tra các mục sau trước khi gửi lại cho đội kỹ thuật:

✔Hạng mục kiểm tra
☐Đã điền 4_San_pham.xlsx (bắt buộc) và 5_Thong_tin_cua_hang.xlsx (bắt buộc).
☐Đã điền 1_Danh_muc, 3_Showroom (và 2_Thuong_hieu nếu dùng).
☐Tên Danh mục/Thương hiệu/Showroom trong file sản phẩm khớp với file 1/2/3.
☐Giá tiền chỉ gồm số, không dấu phân cách.
☐Mỗi ô ảnh đã ghi đúng tên file.
☐Đã gom tất cả ảnh vào 1 thư mục (.zip), tên file khớp với trong Excel.
☐Gửi tất cả (Excel + ảnh) cho đội kỹ thuật qua kênh đã thống nhất.
📦Sau khi nhận, đội kỹ thuật sẽ tạo dữ liệu khởi tạo (seed) cho website production và bàn giao cho bạn kiểm tra. Nếu có dòng nào thiếu/sai, chúng tôi sẽ báo lại để bạn bổ sung.
